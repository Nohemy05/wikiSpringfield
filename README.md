# Wiki Springfield

Bienvenido a la Wiki Springfield, un sitio web estático dedicado a presentar información sobre los personajes más icónicos de la ciudad de Springfield, con especial enfoque en Homero Simpson y la familia Simpson.

Este proyecto tiene como objetivo ofrecer una experiencia visual sencilla, educativa y atractiva para los visitantes interesados en conocer más sobre el universo de Los Simpson.

## 📖 Descripción del proyecto

Wiki Springfield es una página web informativa construida con tecnologías básicas de desarrollo frontend. Su propósito principal es servir como una guía visual y estática sobre personajes destacados de la serie, permitiendo navegar entre secciones como:

- Inicio
- Homer Simpson
- Familia Simpson

El sitio está pensado para ser fácil de mantener, ligero y accesible, ideal para proyectos educativos o como base para futuras ampliaciones.

## 🚀 Instalación y uso

Este proyecto es un sitio web estático, por lo que no requiere una instalación compleja.

### Opción 1: abrir directamente

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.

### Opción 2: usar un servidor local

Si prefieres visualizarlo con un servidor en vivo, puedes usar herramientas como:

- Visual Studio Code Live Server
- Python HTTP Server
- XAMPP o cualquier servidor local

Ejemplo básico con Python:

```bash
python -m http.server 8000
```

Luego abre en tu navegador:

```text
http://localhost:8000
```
